# כרם · משחק מילים עברי

אפליקציית משחק מילים עברית לילדים, צבעונית, מגעית, קלה לפריסה, עם מיתוג כרם: גפנים, אשכולות ענבים, ושלבים אקראיים מתוך קורפוס מילים עברי.

## מה חדש בגרסה הזאת

- החלקת אצבע על אשכולות הענבים: גוררים בין אותיות, ובהרמת האצבע כרם מנסה את המילה.
- כפתור **שלב קורפוס**: יוצר לוח אקראי חדש מתוך קורפוס מילים עברי.
- טעינת קורפוס מהרשת מתוך `eyaler/hebrew_wordlists`, עם מטמון מקומי קטן כדי שגם אחרי טעינה אחת המשחק יישאר זריז.
- גיבוי מקומי קטן אם אין רשת או אם GitHub לא זמין.
- סטטוס קורפוס במסך המשחק וכפתור רענון בהגדרות.
- שלבי משפט מאוירים: מוצאים את מילות המשפט, ומילים נוספות מאותו סט אותיות מתקבלות כבונוס.
- כלי מקומי להצעת שלבי משפט ארוכים מתוך הקורפוס: `python3 tools/sentence_level_scanner.py --limit 20`.
- עדיין כולל את עורך השלבים להורים, צלילים, קונפטי, ניקוד, רמזים, אותיות סופיות ושמירת התקדמות בדפדפן.

## הפעלה מהירה

פתחו את `index.html` בדפדפן לבדיקה מהירה. בשביל התקנה למסך הבית באייפד או שימוש במטמון האופליין, הגישו את התיקייה דרך HTTP:

```bash
python3 -m http.server 4173
```

ואז פתחו את `http://localhost:4173` במחשב, או את כתובת ה־LAN של המחשב מתוך Safari באייפד. בשביל טעינת הקורפוס הגדול צריך חיבור רשת. אם הדפדפן חוסם טעינה חיצונית, המשחק עדיין עובד עם המיני קורפוס המובנה.

## שימוש באייפד או בטלפון

פתחו את האתר ב־Safari ואז השתמשו ב־Share → Add to Home Screen. החבילה כוללת manifest, service worker, ואייקוני PNG למסך הבית של iOS. המשחק מותאם למסכי מגע וההחלקה על האותיות מבטלת גלילה באזור הכרם כדי שהאצבע תישאר במשחק.

## איך שלבי הקורפוס נוצרים

האפליקציה טוענת רשימת מילים, מסננת מילים עבריות באורך 3 עד 9 אותיות, מחפשת קבוצות של שבע אותיות שיכולות לייצר מספר סביר של מילים, בוחרת אות מרכזית, ואז יוצרת שלב שמכיל רק מילים שמשתמשות באותיות האלו וכוללות את האות המרכזית.

הסינון מכוון למשחק ילדים ולא למילון מלא. קורפוס גדול יכול להכיל מילים נדירות, נטיות מוזרות או צורות שפחות מתאימות לילדים, ולכן עורך ההורים נשאר הדרך הכי טובה לשלבים לימודיים מדויקים.

## יצירת שלבי משפט

שלבי המשפט המובנים נשמרים בקוד עם איורים מקומיים תחת `assets/sentence-art/`. הם לא מחייבים את האות המרכזית, כדי לאפשר משפטים טבעיים יותר, אבל כל מילת יעד עדיין חייבת להשתמש רק בשבע אותיות הכרם.

כדי לקבל רעיונות חדשים מתוך הקורפוס, הריצו:

```bash
python3 tools/sentence_level_scanner.py --limit 20
```

הכלי מדפיס מועמדים לבדיקה אנושית, כולל אותיות, אות מרכזית מוצעת, מילות יעד ודוגמאות למילות בונוס.
